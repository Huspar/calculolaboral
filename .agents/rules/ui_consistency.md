# Regla de Consistencia UI: Header y Footer Estándar

Toda página HTML del proyecto `calculolaboral.cl` debe implementar de forma exacta e inalterada el encabezado (Header con logo SVG oficial de balanza) y el pie de página (Footer blanco de 4 columnas) definidos en `AGENTS.md` e `index.html`.

### Puntos Críticos Obligatorios:
1. **Logo Oficial:** SVG de balanza con monograma C y L en contenedor azul `bg-sky-500` con `CálculoLaboral`. Nunca usar texto plano `CL`.
2. **Color Footer:** Siempre `bg-white border-t border-slate-200`. Prohibido el fondo oscuro `bg-slate-900`.
3. **Indicadores:** Carousel con `whitespace-nowrap` en etiquetas.
